# Package `@fitchgc/pi-team`, repo `fitchgc/pi-team`, MIT license

The npm package is `@fitchgc/pi-team`, the GitHub repository is `fitchgc/pi-team`, and the license is MIT.

The unscoped names `pi-team` and `pi-orchestrate` were already taken on npm (checked 2026-11-24). The scoped name keeps the package and the repository under one identity and leaves the unscoped `pi-agent-team` (still free) unused. MIT is the default permissive choice: it lets anyone use the plugin, including commercially, and matches the ecosystem's norm for Pi extensions.
